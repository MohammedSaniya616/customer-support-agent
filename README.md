# Customer Support Resolution Agent

An AI-powered customer support agent built using Python and Claude-style tool architecture.

## Features

* Customer verification
* Order lookup
* Refund processing
* Human escalation workflow
* Multi-order disambiguation
* Refund safety guardrails

## Tools

* get_customer
* lookup_order
* process_refund
* escalate_to_human

## Technologies Used

* Python
* JSON
* Tool-based agent architecture

## Project Workflow

1. Verify customer
2. Lookup orders
3. Detect multiple similar products
4. Process or escalate refund
5. Generate escalation summary
